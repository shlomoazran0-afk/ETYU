# 🎮 ETYU Engine 3D

מנוע משחקים תלת־ממדי מלא שרץ כולו בדפדפן — בלי התקנות, בלי build, בלי קבצי מדיה.
כל הנכסים (טקסטורות, מודלים, סאונד) נוצרים פרוצדורלית בקוד.

## הרצה

```bash
npm start          # שרת סטטי על פורט 8123
# או: python3 -m http.server 8123 --bind 0.0.0.0
```

ואז פתחו http://localhost:8123

## המשחקים שעל המנוע

| משחק | ז'אנר | תיאור |
|---|---|---|
| 🚁 צייד המל״טים | FPS | זירה עם כוונת, ירי, פיצוצים וגלים של מל״טים מתקדמים |
| 💎 מסע בין האיים | פלטפורמר | איים מרחפים (כולל נעים), 12 אבני חן, נקודות ביקורת ופורטל |
| 🏎️ כביש הטורבו | מירוץ אינסופי | שקיעה סגולה, מכשולים, מטבעות ובוסטים במהירות עולה |
| 💥 מגרש ההרס | סנדבוקס פיזיקה | ירי כדורים, ניפוץ ארגזים ופיצוצי חביות משורשרים |

## מה יש במנוע (`engine/`)

- **`core.js`** — ליבה: WebGL renderer, לולאת משחק עם dt מוגבל, ניהול משחקים, הפסקה, מסכי סיום. מחלקת בסיס `Game` לכל משחק.
- **`physics.js`** — מנוע פיזיקה ייעודי: כבידה, AABB מול תיבות סטטיות, כדורים מול תיבות (closest-point), כדור-בכדור עם שימור תנע, חיכוך, ריבאונד, העלאת מדרגות אוטומטית (auto-step), פלטפורמות נעות שגוררות אחריהן, ו-hooks של עוצמת פגיעה (`onImpact`).
- **`assets.js`** — ספריית נכסים פרוצדורלית: טקסטורות קנבס (עץ, ארגזים, לבנים, כביש, סורג-טק...) ומפעל מודלים — בניינים, עצים, דקלים, סלעים, חביות, ארגזים, מל״טים, מכונית מרוץ, אבני חן, פורטל, עננים ועוד.
- **`world.js`** — סביבות: כיפת שמיים עם גרדיאנט (שיידר), ערפל, תאורת יום/שקיעה/לילה עם צללים רכים, כוכבים וקרקע.
- **`effects.js`** — חלקיקים עם מיחזור (עד 360), פסי ירי, פיצוצים.
- **`sfx.js`** — סינתיסייזר WebAudio: כל הצלילים נוצרים בזמן אמת (ירי, פיצוצים, מטבעות, בוסט, ניצחון...).
- **`hud.js`** — ממשק בעברית: ניקוד, בריאות, כוונת, מסרים, טוסטים, תפריטי הפסקה וסיום.
- **`input.js`** — מקלדת + עכבר + Pointer Lock, עם just-pressed וצירי תנועה.

## קידוד משחק חדש על המנוע

```js
import { Game } from '../engine/core.js';

export class MyGame extends Game {
  init() { /* בניית עולם, שחקן, HUD */ }
  update(dt) { /* לוגיקה בכל פריים */ }
}

export { MyGame as Game };
```

הוסיפו כרטיס ב-`index.html` ורשומה ב-`LOADERS` ב-`js/main.js` — וזהו.

## טכנולוגיה

- three.js (מקומם ב-`vendor/`) לרינדור WebGL
- JavaScript טהור (ES Modules + Import Maps) — בלי כלי build
- פיזיקה, HUD, סאונד ואפקטים — כולם נכתבו מאפס בריפו הזה
